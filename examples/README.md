# pyXLMS Examples

In this directory you can find example notebooks on how to use pyXLMS, documenting
almost all of the functionality that is available in the pyXLMS package.

> [!IMPORTANT]
>
> We recommend reading the guide at [hgb-bin-proteomics.github.io/pyXLMS-docs](https://hgb-bin-proteomics.github.io/pyXLMS-docs)
> along with the notebooks as it gives complimentary and necessary information!

## Running Example Notebooks

You can run the example notebooks via the following steps:

- Install pyXLMS
  ```bash
  pip install pyxlms
  ```
- Install [JupyterLab](https://jupyter.org/)
  ```bash
  pip install jupyterlab
  ```
- Clone the [pyXLMS Repository](https://github.com/hgb-bin-proteomics/pyXLMS)
  ```bash
  git clone --depth 1 https://github.com/hgb-bin-proteomics/pyXLMS.git
  ```
- Change to the pyXLMS Directory
  ```bash
  cd pyXLMS
  ```
- Launch JupyterLab
  ```bash
  jupyter lab
  ```
- Run Example Notebooks
  - Navigate to the notebook you want to run in the JupyterLab file browser and open it.
  - Execute the cells from top to bottom.
